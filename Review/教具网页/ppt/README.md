# Web Coding × AI 协作课堂复盘 · 瑞士风翻页 PPT

30 页单文件横向翻页 PPT,基于 `guizang-ppt-skill`(风格 B · 瑞士国际主义)生成。

## 文件

- `index.html` — 完整 deck(单文件,双击即可打开;含 WebGL 网格、ASCII 呼吸场、Motion One 动效、ESC 索引、B 低功耗)
- `assets/motion.min.js` — Motion One 本地副本(离线兜底,勿删)
- `images/` — 配图目录(当前无图,纯文字版式;如后续补图,命名 `{页号}-{语义}.{ext}`)

## 迭代注意

- 加页/删页后:改各页 `chrome-min` 右侧页码 `XX / N`,并同步本表的页数
- 换主题色:从 `guizang-ppt-skill/references/themes-swiss.md` 复制 `:root` 块整体替换(柠檬黄已替换完成,注意柠檬黄下 accent 页用深色文字,模板里有 `柠檬黄适配` 一节 CSS)
- 改文案直接编辑对应 `<section>`,字体/字号/字重按 skill 的字号阶梯守则(小字 ≥14px / 卡片 ≥16px / 正文 ≥18px;大字 200、越细越大)
- 校验:`node <SKILL_ROOT>/scripts/validate-swiss-deck.mjs index.html`
- 图片:当前纯文字;若补图,单张大图用 S22(`data-image-slot="s22-hero-21x9"`,21:9),多图用 S15/S16 网格改造
