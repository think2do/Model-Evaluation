# Web Coding × AI 协作课堂复盘｜Step 01–05

这是一个独立的静态长网页，用于课堂展示以下五步：

1. 检查并改写评测题生成提示词；
2. 用改写后的模板生成小红书文案评测题与 13 项二元评分标准；
3. 将生成的题目交给模型，得到待评回答。
4. 使用同一问题、评分标准和回答进行重复裁判，检查稳定性；
5. 通过需求澄清、任务拆分和 M1–M9 增量交付，完成本地模型回答裁判器。

## 课堂重点

前四步用于交代“为什么会产生这个工具”，第五步是主要教学章节。Step 05 按《Web Coding × AI 协作执行清单》组织为九个环节：

1. 需求澄清与范围确定；
2. 技术方案设计；
3. 任务拆解与排期；
4. 环境搭建与脚手架；
5. 分模块开发实现；
6. 自测与代码走查；
7. 集成联调；
8. 测试与验收；
9. 开发完成确认。

每个环节都回答四个问题：产出物是什么、AI 做什么、你做什么、什么算完成，并对应到本项目的真实文件、对话决策或验证记录。

Step 05 还包含项目文件导读：

- `index.html`：页面结构；
- `styles.css`：布局、响应式和状态样式；
- `app.js`：输入、校验、请求、解析、排名和结果渲染；
- `config.example.js` / `.gitignore`：本地凭证边界；
- `README.md`：运行方式、功能边界和开源前检查。

当前可见 Git 历史为 `M3 → M4 → M5 → M6 → M7 → M7.1 → M8 → M9`。因为可见历史从 M3 开始，页面没有把 M1、M2 描述为可独立追溯的提交。

## 打开方式

直接打开 `index.html`，或在本目录启动任意静态文件服务器。
