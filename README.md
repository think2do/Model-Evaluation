# 模型回答裁判器

一个仅在本地浏览器中使用的轻量模型评测网页。用户提供原始问题、二元评分标准和多份模型回答，网页调用 DeepSeek V4 Flash，展示逐项判定、证据、分数及排名。

## 功能

- 创建、切换、命名和删除多个评测版本；删除前二次确认。
- 输入原始问题和对应评分标准。
- 手动添加多份“模型名称 + 模型回答”。
- 支持单条、当前版本未评测记录、当前版本全部记录和多版本评测。
- 每份回答独立调用 `deepseek-v4-flash`，批量最大并发数为 99，并可手动终止。
- 展示红线、原始分、最终分、得分率和每个 C 项的直接证据。
- 对结构化成功的结果按最终分排序；同分并列。
- 保存未评测、成功、请求失败、解析失败和已终止状态；重新评测以最新结果覆盖，终止重新评测时保留旧成功结果。
- 将全部版本导出为单工作表 Excel，并可用合法行全量导入替换网页数据。

## 本地使用

### 1. 配置 API Key

复制示例配置：

```bash
cp config.example.js config.js
```

打开本地的 `config.js`，只填写自己的 DeepSeek API Key：

```js
window.MODEL_EVALUATION_CONFIG = {
  deepSeekApiKey: "在本地填写你的 Key",
};
```

`config.js` 已被 `.gitignore` 排除，不应加入 Git。

### 2. 打开网页

直接双击 `index.html`，或使用静态文件服务器打开。项目不需要安装依赖、启动后端或运行构建命令。

### 3. 完成一次评测

1. 在左侧粘贴原始问题和评分标准。
2. 在右侧填写模型名称和回答。
3. 点击“添加回答”录入更多待评回答，并通过标签切换。
4. 选择需要的评测入口。
5. 请求结束后，在底部查看排名，并通过模型标签切换逐项结果。
6. 需要保存或迁移当前全部数据时，使用 Excel 导出或导入。

## 数据与安全边界

- API Key 仍由浏览器前端读取。任何能读取本地文件、页面源码或浏览器运行状态的人都可能获取它。
- 仅限个人本地使用；不要把填写了 Key 的 `config.js` 分享、上传或部署到公网。
- 数据只保存在当前页面内存和用户主动导出的 Excel 中；刷新或关闭页面后，未导出的数据会消失。
- 导入是“合法行全量替换”，不是追加；错误行会跳过并列出。
- Excel 公式或宏不会执行，检测到公式或宏时拒绝导入。
- 不提供后端、登录、数据库、历史记录、题库或多人协作。
- 不生成题目、评分标准或待评模型回答。
- 不自动修复裁判返回；不合规结果会要求人工复核。
