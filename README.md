# 模型回答裁判器

一个仅在本地浏览器中使用的轻量模型评测网页。用户提供原始问题、二元评分标准和多份模型回答，网页调用 DeepSeek V4 Flash，展示逐项判定、证据、分数及排名。

## 功能

- 输入原始问题和对应评分标准。
- 手动添加多份“模型名称 + 模型回答”。
- 每份回答独立调用 `deepseek-v4-flash`。
- 展示红线、原始分、最终分、得分率和每个 C 项的直接证据。
- 对结构化成功的结果按最终分排序；同分并列。
- 请求失败或结构化失败时保留明确状态；结构化失败可查看原始返回。

## 本地使用

### 1. 配置 API Key

复制示例配置：

```bash
cp config.example.js config.js
```

打开本地的 `config.js`，只填写自己的 DeepSeek API Key：

```js
window.MODEL_EVALUATION_CONFIG = {
  deepSeekApiKey: "在本地填写你的 Key",
};
```

`config.js` 已被 `.gitignore` 排除，不应加入 Git。

### 2. 打开网页

直接双击 `index.html`，或将它拖入浏览器打开。第一版不需要安装依赖、启动后端或运行构建命令。

### 3. 完成一次评测

1. 在左侧粘贴原始问题和评分标准。
2. 在右侧填写模型名称和回答。
3. 点击“添加回答”录入更多待评回答，并通过标签切换。
4. 点击“开始评测”。
5. 请求结束后，在底部查看排名，并通过模型标签切换逐项结果。

## 数据与安全边界

- API Key 仍由浏览器前端读取。任何能读取本地文件、页面源码或浏览器运行状态的人都可能获取它。
- 仅限个人本地使用；不要把填写了 Key 的 `config.js` 分享、上传或部署到公网。
- 不保存题目、标准、回答或评测结果；刷新或关闭页面后数据消失。
- 不提供后端、登录、数据库、历史记录、题库或多人协作。
- 不生成题目、评分标准或待评模型回答。
- 不自动修复裁判返回；不合规结果会要求人工复核。
