# A2 版本任务清单

本清单根据以下文档整理：

- [A2 版本需求说明](需求文档.md)
- [A2 技术选型与架构说明](A2技术选型与架构说明.md)

开发按九个阶段依次进行。每个阶段应形成一个可以独立验收的产出，原则上可以在一次对话或一个 commit 内完成。

---

## 阶段一：锁定开发规则

### 目标

把已确认的 A2 边界同步为开发和验收基线。

### 关键产出

- 同版本公共字段冲突时跳过冲突行；
- 批量评测最大并发请求数固定为 99；
- 评测期间禁止导入和导出；
- 评测过程提供手动终止能力；
- 首次导出同步更新第一次导出时间和最后更新时间；
- Excel 没有合法行时保留网页当前数据；
- 手动终止后，没有旧成功结果的记录进入“已终止”状态；
- 重新评测被终止时，已有成功结果的记录保留旧结果和“评测成功”状态。

### 验收标准

- 所有状态和覆盖规则均有唯一结论；
- 需求文档和架构文档同步更新；
- 后续开发不再依赖未说明的假设。

---

## 阶段二：建立 A2 数据结构

### 目标

将现有单次评测数据改造成可以同时保存多个评测版本的内存结构。

### 关键产出

- 评测版本和评测记录的数据结构；
- 版本、记录和评测状态常量；
- 唯一 ID 生成规则；
- 版本级内存 Store；
- 创建、更新、删除和全量替换数据的方法；
- `firstExportedAt` 和 `updatedAt` 时间规则。

### 验收标准

- 可以同时保存多个评测版本；
- 版本名称允许为空，版本 ID 必须唯一；
- 每个版本独立保存问题、评分标准和多条回答；
- 修改版本或记录时正确更新版本时间；
- 只切换显示版本时不更新时间；
- 核心数据操作具有自动化测试。

---

## 阶段三：实现评测版本管理界面

### 目标

让用户可以在网页中创建、切换、编辑和删除多个评测版本。

### 关键产出

- 版本列表和无版本空状态；
- 新建版本入口；
- 版本切换；
- 版本名称、问题和评分标准编辑；
- 版本内模型回答管理；
- 删除版本二次确认；
- 桌面和窄屏基础布局。

### 验收标准

- 用户可以连续创建多个版本；
- 不同版本的数据互不影响；
- 版本名称为空时仍能正常显示和切换；
- 删除前必须二次确认；
- 删除版本时同时删除其全部记录；
- 删除最后一个版本后返回明确空状态。

---

## 阶段四：迁移并扩展评测功能

### 目标

把现有裁判请求、严格解析和结果展示能力接入新的版本数据结构。

### 关键产出

- “版本公共字段 + 单条记录”的请求构造；
- 统一评测任务编排器；
- 并发队列和进度状态；
- 最大同时请求数为 99；
- 单条记录评测；
- 当前版本全部未评测记录评测；
- 当前版本全部记录重新评测；
- 多版本评测；
- 手动终止本次评测；
- 最新结果覆盖旧结果。

### 验收标准

- 四种评测操作均可使用；
- 问题和标准来自记录所属版本；
- 同时发出的请求不超过 99 个，超出任务进入等待；
- 单条失败不阻止其他任务；
- 用户可以终止等待和进行中的评测任务；
- 没有旧成功结果的终止任务保存为“已终止”；
- 已有成功结果的重新评测被终止时，保留旧结果和“评测成功”状态；
- 最新成功、请求失败或解析失败都会覆盖旧状态；
- 不保留被覆盖的旧结果；
- 评测完成后正确更新所属版本时间；
- 不改变现有裁判规则和严格解析原则。

---

## 阶段五：建立 Excel 数据规范

### 目标

固定 A2 Excel 格式，并完成内存数据与 Excel 行之间的转换。

### 关键产出

- 引入本地固定版本的 SheetJS CE；
- 第三方许可证和来源说明；
- Excel 数据格式版本；
- 单工作表名称和固定列结构；
- 状态与字段组合规则；
- 内存对象转 Excel 行；
- Excel 行转候选数据；
- 完整评测结果 JSON 序列化和解析。

### 验收标准

- Excel 只使用一个工作表；
- 每条模型回答记录占一行；
- 同版本公共字段在各行重复保存；
- 完整结果保存在 JSON 列；
- 最终分、满分和得分率具有独立列；
- 数据可以完成导出再导入的往返转换；
- SheetJS 可以离线加载，版本和许可证可追溯。

---

## 阶段六：实现 Excel 导出

### 目标

将网页当前保存的全部评测版本导出为一个可重新导入的 `.xlsx` 文件。

### 关键产出

- 单工作表 Workbook 生成；
- “导出全部数据”入口；
- 文件名规则；
- 浏览器文件下载；
- 第一次导出时间写入；
- 导出成功和失败提示。

### 验收标准

- 导出包含网页当前的全部版本和记录；
- 已删除版本不进入新文件；
- 只有一个工作表；
- 中文、长文本和 JSON 不丢失；
- 首次成功导出时写入版本级第一次导出时间；
- 首次成功导出同时更新版本级最后更新时间；
- 后续导出不覆盖第一次导出时间；
- 导出失败时不写入时间，也不显示成功；
- 评测尚未结束时禁止导出；
- 文件可以在目标桌面表格软件中正常打开。

---

## 阶段七：实现 Excel 导入

### 目标

读取 Excel 中的合法数据，用其替换网页当前数据，并报告被跳过的错误行。

### 关键产出

- Excel 文件选择和读取；
- 工作簿、工作表、列名和格式版本校验；
- 行级字段校验；
- 结果 JSON 严格校验；
- 摘要分数与 JSON 一致性校验；
- 同版本公共字段一致性校验；
- 合法数据全量替换；
- 错误行报告。

### 验收标准

- 文件整体无法识别时保留网页原有数据；
- 文件结构有效时导入合法行；
- 错误行被跳过并列出实际行号和具体原因；
- 同版本公共字段冲突时只跳过冲突行；
- 导入不是追加、合并或去重；
- 导入不改变原有时间字段；
- 没有任何合法行时保留网页当前数据；
- 评测尚未结束时禁止导入；
- 未评测、成功、请求失败、解析失败和已终止状态均能恢复；
- 非法或矛盾数据不会被自动修复。

---

## 阶段八：完善交互、安全与响应式布局

### 目标

处理导入、导出、评测之间的竞态，并保证文件内容和页面交互安全可用。

### 关键产出

- 页面级忙碌状态；
- 重复点击和并发操作保护；
- 评测期间禁用导入和导出；
- 手动终止评测及操作状态恢复；
- Excel 公式、宏和脚本处理规则；
- 用户文本安全渲染；
- 版本列表和确认对话框的键盘操作；
- 导入结果的无障碍提示；
- 桌面、820px 和 480px 响应式布局。

### 验收标准

- 导入、导出和评测不会互相破坏数据；
- 评测结束或终止流程完成后才恢复导入导出；
- 任一操作失败后控件可以恢复；
- 不执行 Excel 公式、宏或脚本；
- 用户文本、模型文本和 JSON 不作为 HTML 执行；
- 键盘可以完成核心操作；
- 窄屏可以完成版本管理、评测、导入和导出；
- 长文本和错误信息不会撑破页面。

---

## 阶段九：测试、验收与文档交接

### 目标

完成 A2 的自动化测试、浏览器验收、安全检查和项目文档同步。

### 关键产出

- 数据 Store、时间规则和覆盖规则测试；
- Excel 映射、导入校验和错误行测试；
- 完整浏览器验收清单；
- 桌面和窄屏验收；
- 凭据扫描和第三方许可证检查；
- README、项目上下文、架构、路线图、更新记录和 TODO 更新；
- 本任务清单完成状态更新。

### 验收标准

- 核心自动化测试全部通过；
- 创建、切换和删除多个版本通过浏览器验收；
- 四种评测操作通过验收；
- 最大并发请求数为 99；
- 手动终止评测通过验收；
- 评测期间无法导入和导出；
- 单表导入导出通过验收；
- 时间与覆盖规则符合需求；
- 部分错误 Excel 可以导入合法行并返回错误清单；
- 新增内容不包含真实 API Key 或真实用户数据；
- `config.js` 继续保持 Git 忽略；
- 第三方依赖来源和许可证完整；
- 文档只描述实际完成和实际验证的行为。

---

## A2 完成定义

A2 只有在九个阶段全部验收后才可以标记为完成：

- 支持创建和管理多个评测版本；
- 支持四种评测操作；
- 最新结果或错误可以正确覆盖旧结果；
- 支持单工作表 Excel 全量导出；
- 支持合法行导入和错误行报告；
- 版本级时间规则正确；
- 删除版本具有二次确认；
- 自动化测试和浏览器验收完成；
- 新增内容通过凭据与许可证检查；
- 项目文档与最终代码一致。
